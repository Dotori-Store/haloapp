#1.검색장면

이 장면은 search 를 눌렀을 때 나타나는 장면.
처음 바텀시트가 좁아졌을때와 중간정도 올라갔을 때 search 를 터치하면 나타나는 장면.
바텀시트가 화면을 거의 채우고, 배터리 이미지만 나올정도. top : 60px
즉, 검색 장면이 됨.
검색 필드의 뒤로가기 버튼을 누르면 바텀시트가 작은 높이(168px)로 돌아감.
바텀시트를 쓸어 내렸을 때도 작은 높이(168px)로 돌아감( 이 부분이 가능한지, 자연스러운 건지 니 답변도 함께 줘.)
이 때는 filter-bar 가 사라짐.

실제 검색 기능은 구현하지 않아도 됨.
화면과 같이 최대치의 결과 더미만 보여주면 되고, 이 역시 바로 아래의 버튼을 가리지 않는 높이가
필요함.
즉, 상단은 검색 바, 중앙은 검색결과(더미), 그 다음은 'Can't find it? Recommend!' 버튼.
이때 버튼 font-size : 14, height 50, 좌우 padding 20 이고,

검색결과의 양과 상관없이 바텀시트내에서 항상 아래에 위치.
즉 검색결과 container 는 flex-grow 1 이 됨.

좀전에 말했다 시피, 이건 시연용이야.
검색 같은 경우 검색 결과가 없을 경우도 보여줘야 하는데, 그럼 db를 실제 구현을 해야잖아.
그렇게는 할 필요가 없어. 그래서 아무 글자를 넣으면 검색결과가 없는 화면을 보여주고 싶어. 이게 좋은 방법일까.
